# **App Name**: KodNest Premium

## Core Features:

- State-Synchronized Top Bar: Navigation layer featuring project naming, step-by-step progress tracking, and dynamic status badges for shipping readiness.
- Intelligent Prompt Architect: An AI-powered tool within the secondary panel that refines user build instructions into precise code prompts.
- Bifurcated Workflow Engine: A layout system with a 70/30 split between the primary interactive workspace and the calm secondary action panel.
- Requirement Proofing Engine: A persistent footer containing a rigorous checklist of UI, Logic, Testing, and Deployment validation gates.
- Semantic Prompt Clipboard: Single-action prompt replication with integrated tracking of usage history and status transitions.
- Step Validation AI: An AI tool that verifies the accuracy of uploaded build proof against the current step objectives.

## Style Guidelines:

- Calm light-mode palette: Background #F7F6F3 (Bone), Primary Text #111111 (Night), and Accent #8B0000 (Deep Crimson) for high-intent actions.
- Pairing of 'Literata' (Serif) for confident headings with generous tracking, and 'Inter' (Sans-serif) for clean, highly-readable body text.
- Strict grid-based hierarchy consisting of Top Bar, Context Header, a 70/30 Split Primary/Secondary layout, and a Proof Footer.
- Strict 8pt spacing system (8, 16, 24, 40, 64) to ensure deliberate use of white space and no visual noise.
- Predictable micro-interactions using 150–200ms ease-in-out transitions; absolutely no bounce or parallax.
- Muted, functional iconography for status states: muted green for success and muted amber for warnings, avoiding any saturated colors.
